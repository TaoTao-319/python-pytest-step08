# Python 与 pytest 学习记录

## 已形成的成果

项目包含三个可调用函数、45 个自动化测试场景、一个可直接执行的演示入口，以及真实测试日志、JUnit XML、逐场景 CSV 和终端输出记录图。源码、测试和说明分别放在 `src`、`tests` 和 `docs`。

已有代码先复制到当前工作空间再调整。原有 40 个场景保留，新增 5 个购物车规则场景；测试文件中带时间编号的说明已改成主题描述。

## 需要掌握的知识

| 知识点 | 在项目中对应什么 | 自己应能解释的问题 |

| 参数化 | `test_validators.py` 中的多组输入 | 为什么数据的一行会成为独立场景？ |

| 运行证据 | 日志、XML、CSV 和记录图 | 怎样证明测试真正执行过？ |

## 整理过程中的问题与处理

直接使用 `src` 结构时，pytest 和直接执行脚本的模块搜索路径不同。pytest 使用 `pytest.ini` 配置；演示入口 `demo.py` 根据自身位置添加源码目录，因此可以直接运行。

金额计算原来依赖 Decimal 当前上下文的舍入设置。现在函数明确指定 `ROUND_HALF_EVEN`，并通过切换外部舍入模式的测试确认规则稳定。

运行环境对系统临时目录存在访问限制，虚拟环境依赖安装已在允许执行的环境中完成；独立副本验证会使用已下载的依赖包离线安装。项目使用者仍可以按 README 的普通安装方式操作。
