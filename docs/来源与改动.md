# 来源与改动说明

复用了用户已有的 Python 与 pytest 项目。读取原项目后，把源码、测试、README、依赖和配置共 11 个文件复制到当前工作空间，再对这里的副本调整。没有复制原项目的虚拟环境、Git 内部目录或缓存。

`source_inventory.csv` 记录各文件的原始 SHA-256 和刚复制时的 SHA-256；两列一致可以证明复制内容一致。最终源文件复核见 `artifacts/source_integrity.json`。

## 对副本的改动

- 保留 40 个原有测试场景，补充 5 个购物车场景。
- `cart.py` 明确采用 `ROUND_HALF_EVEN`，避免舍入结果受到外部舍入模式设置影响。
- 将带时间编号的测试模块说明改为按主题命名。
- 更新 README，增加演示入口、证据生成工具、隔离的失败演示，以及测试设计、项目介绍和复核说明。
- 增加真实日志、JUnit XML、逐场景结果、终端输出记录图与可分享压缩包。

数据校验规则保持与原项目一致。项目说明、测试数量和执行证据都以当前副本为准。
