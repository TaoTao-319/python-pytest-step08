# pytest 失败输出阅读与排查

`examples/failure_example.py` 是隔离的错误预期演示，默认测试目录为 `tests`，因此它不会进入正常测试集。显式运行这个例子时，预期得到一条失败和退出码 1。

```powershell
.\.venv\Scripts\python.exe -m pytest examples/failure_example.py -v --tb=short
```

演示中两件商品的正确总价是 `3.25 × 2 + 10.00 × 1 = 16.50`，断言却故意写成 `16.00`。日志会显示实际值 `Decimal('16.50')` 与预期值 `Decimal('16.00')` 不一致。这是测试预期设置错误的教学示例，不是声称发现了函数缺陷。

排查时按以下顺序操作：

1. 找到失败用例名称和断言所在行，确认失败发生在计算结果比较，而不是导入或环境准备。
2. 读出实际值和预期值，并检查输入数据。
3. 依据规则手工计算 `3.25 × 2 + 10.00 × 1`，得到 `16.50`。
4. 在自己的临时副本中把预期改成 `Decimal("16.50")`，运行同一用例确认通过。本项目保留原演示文件，方便再次复现失败。
5. 运行默认测试集，确认正式测试仍全部通过。

证据文件：

- `artifacts/pytest-failure.txt`：真实执行的失败日志。
- `artifacts/pytest-pass.txt`：默认测试集的真实通过日志。
- `artifacts/pytest-failure.png` 与 `artifacts/pytest-pass.png`：由对应真实日志绘制的终端输出记录图，便于展示；不是桌面截图。

金额舍入的实际改进与演示失败分开记录：函数显式指定 `ROUND_HALF_EVEN`，新增测试验证外部舍入模式变化后结果仍符合项目规则，详见测试设计与来源改动说明。
